# Sync, Send and the desktop app: detailed notes

Moved out of `CLAUDE.md` (it is read at the start of every session; this is read only when working on these parts). Kept as it was written, so some wording is older than the code: check the code when in doubt.

- `sync.js` (`Sync`, plain functions like `decor.js`, tested in `tests/sync.test.js`): the rules for keeping devices in step; the server is `worker/sync/` (Cloudflare Worker + D1, `npm run build:worker` rebuilds `dist/worker.js` after changing `sync.js` or `server.js`, a test checks) (see `docs/design/desktop-companion-and-sync.md`). `state.sync` is a table of when each item and single thing last changed, filled by `Sync.stamp` inside `save()` (so no other code has to know about it); `snapshot` makes a document, `merge` joins two (same result in any order), `apply` writes one back. Only the shopping list syncs (to-dos stay private, never stamped or touched). Items merge whole, latest change wins, with removed markers kept 30 days; counters keep the larger value. New item ids end in `-<device>` (`newId`). Keep new pet data in `state.pet` and list it in `sync.js` (a `FIELDS` entry for single things, `COUNTERS` for counters), or it won't sync; things that belong to one device (sleep, options, which list is showing) are left out on purpose. `app-account.js`: Backup & sync (Options): the account is a recovery code kept in `localStorage` `nibble.account` (never synced), `syncNow` posts `Sync.snapshot` (sample items skipped) to the Worker in `worker/sync/` and joins the answer with `Sync.sync`; it runs 4 s after a saved change, on opening, on coming online and every 2 minutes; a device joining an account that has a list drops its sample list (`Sync.dropSample`). `send.js` (`Send`, tested in `tests/send.test.js`): what counts as a link or a note, shared-page handling, how a received message is shown. `app-send.js` (the eating animation waits for him to be free, `whenCanEat`, and the receiver waits ~2 s so the sender's animation can be watched): Options > Send to another device (the sheet, the manifest's `share_target` opens it with the shared link; it works phone to PC and PC to phone), and on every device (the desktop app always; elsewhere unless Receive is switched off) `inboxPoll` every 10 s fetches `/v1/inbox?device=<id>` (what other devices left, never its own), Fumu eats the message (`receiveMessage`) and an `.inbox-card` shows it (Open / Copy / done; done acks it on the server). `app-desktop.js`: only runs inside the Windows desktop shell in `desktop/` (Electron; see `desktop/README.md`; `windows.js`, `privacy.js` and `place.js` are listed in the installer's `files`): `window.nibbleDesktop` comes from its preload; `html.desktop-pet` shows Fumu alone on a transparent window, `html.desktop-list` the whole app with a bar (CSS at the end of `styles.css`); hold still on him to carry the window (the shell follows the cursor itself while carried, `dragFollow`; the page wiggles him with `drawBody`, `startCarry`); the shell also tells the page which part of the window is on a screen (`onVisible`, `--vis-l`/`--vis-r`) so the speech bubble stays in it. It also does the reminder card (`window.deskRemind`, called first by `timeCheck` in `app-todo.js`: an `.inbox-card.remind-card` with Done / In 10 min, bringing him back if hidden) and his own doings every few minutes (`wander` and `peek` ask the shell to glide the window, `napNow` in `app-idle.js` is a page-only nap; `window.deskDo` runs one for the animation player); the shell registers global shortcuts (`CommandOrControl+Alt+F` small/whole app, `+Alt+T` shopping/to-do via `onSwapList`; a middle click on him and a double-click on the bar do the first with the mouse), and in the small window the lamp counts as off at bedtime (`refreshBedtime` sets `bed.dark` when `html.desktop-pet`, since the lamp is hidden there); `+Alt+S` (held only while the pointer is over him, like the settings key: `HOVER_HANDLERS`, keys marked `hover`) sends the text on the clipboard, a link or a note, to the other device at once (`sendCopied` in `main.js` reads the clipboard and passes the text to the page, `onSendCopied` calls `sendToOther(text)` in `app-send.js`, which says what went wrong in a bubble); `+Alt+A` quick-add box by him (`openQuick`, `.quick-card`; the page asks the shell for the keyboard with `D.typing`); the shell's settings window (`panel-main.js`, `panel.html`, `panel-ui.js`, `panel-preload.js`; opened by the `options` shortcut while the pointer is over him, `hoverKey` in `main.js`, or the right-click menu's More settings; his custom name reaches the shell with `D.setPetName` (menu and panel use it, `{name}` in `keys.js` labels), and in the page use `<span class="pet-name">` or `petName()`, never a hard-coded Fumu, in anything the player reads; one `setPref` in `main.js` serves the menu and the window; `keys.js` holds the shortcut list and rules, tested; `hideToy`/`hideCushion` become `desk-notoy`/`desk-nocushion` on `<html>`; the short right-click menu keeps only everyday choices, put new small-Fumu options in the settings window; developer actions reach the page as `onDo` > `deskDo`) ; clicks are caught by the shell's own hit test: the page publishes the solid rectangles (`solidRects`, `D.setRects`, about 30 Hz when they change; the cushion's invisible area is added by hand, matching `#pet::after`), the shell checks the pointer at about 120 Hz (`place.hitTest`, no IPC); a new solid element must match the `SOLID` selector in `app-desktop.js`; while a button is held that went down on him or the toy the page keeps the window solid (`D.hold`, `pressing` in `app-desktop.js`), because a window that turns click-through mid-drag sends the release to the program behind and strands the toy; the shell also reports idle time (`onIdle`: he naps with `napNow` and greets you; `place.idleStep`), keeps him on a screen when screens change (`place.afterScreensChange`) and, with the tray switch `perch` (off by default), lets him sit on other windows (`desktop/windows.js` lists window frames with `koffi`, never titles; `place.perches`; `hopUp`/`hopDown` in the page; on a perch he gets `.seated` (the `.soles` group in `index.html`, drawn in front of the body, per species: cat toe beans `.sole-paw`, pig hooves `.sole-hoof`, pigeon toes `.sole-bird`; rules next to the feet in `styles.css`, only cat, pig and pigeon so far; extend the `:is([data-species=...])` lists as more are drawn; also in the animation player and the settings' Sit button); with the `toyRoam` switch a carried or thrown toy is drawn by a second transparent window (`toyWin` in `main.js`, moved by the page with `toyAt`; `toyField` in `app-toy.js` widens the toy's limits to the whole screen, `deskToyChase` runs his window along the floor to where it landed); he rests with his soles just clipping into the window he sits on (`perchSink` in `place.js`) and, getting off, drops and runs back to where he stood (`perchOrigin`, `desk:run`); the tray menu holds size (a page zoom), stay above full-screen, nudge/corners, and the roam and remind switches, read by the page with `getPrefs`/`onPrefs`. `desktop/place.js` is tested in `tests/desktop.test.js`; `desktop/` has its own `package.json` and is not part of the Pages deploy. `app-sync.js`: the Developer tools sync log (kept in `localStorage` `nibble.synclog`, never synced) and its "Check merging" self-test.
