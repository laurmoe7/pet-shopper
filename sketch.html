GitHub connection

Uploads go to the drawings branch of your repository, in the drawings folder, so the game itself is never touched. You need to connect once:

  1. On GitHub: your picture, Settings, Developer settings, Personal access tokens, Fine-grained tokens, Generate new token.
  2. Repository access: only laurmoe7/pet-shopper. Permissions, Repository: Contents: Read and write. Nothing else.
  3. Paste the token here. It stays in this browser on this computer, and is only sent to GitHub.
